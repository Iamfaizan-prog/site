02 Workflow 2026

LeadFlow-lite

Takes form and inbox leads through validation and dedupe, scores them hot, warm or cold, and drafts a first reply for a human to send.

  • Dedupe on email and phone
  • Score plus draft in one pass
  • Rows land in Sheets, replies in drafts

Every build

What comes with the code

A script that only works on my machine is not a delivery. These three things ship with every project.

A run log

One line per stage with row counts, warnings and an exit code. If it fails at 2am, the log says which file and which row.

A sample input

A small anonymised file that reproduces the run. It stays in the repo so the code can be tested without client data.

A handover README

How to install, run, change the schedule and read the log, written for the person who inherits it.

Have a step that looks like these

A sample file and the manual steps around it is enough to tell you whether it is worth automating.

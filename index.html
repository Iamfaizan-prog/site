What I build

Three kinds of work, one job: removing the manual pass

Each build starts with the step that eats the most time and ends with something your team can run without me.

  1. 01

    Data pipelines

    Messy exports in, clean workbooks out. Cleaning, dedupe, date repair and formatting run on a schedule, and every run writes a log you can read.

    pandas · openpyxl
    Streamlit

  2. 02

    Workflow automation

    Lead intake, validation, routing and follow-up drafts wired through n8n and webhooks, so nothing waits in an inbox for someone to notice it.

    n8n · webhooks
    Google Sheets API

  3. 03

    Backend APIs

    FastAPI services for the parts other systems call: validation, scoring, report generation and file handling, with tests where they earn their keep.

    FastAPI · Docker
    pytest

DataPilot-lite

Turns raw invoice exports into a formatted Excel workbook and a PDF summary. Dates are repaired, duplicates dropped, totals checked.

  • Sample run: 1,284 rows in, 1,247 kept
  • 37 duplicates and 12 dates fixed

02 Workflow 2026

LeadFlow-lite

Takes form and inbox leads through validation and dedupe, scores them hot, warm or cold, and drafts a first reply for a human to send.

  • Dedupe on email and phone
  • Score plus draft in one pass
  • Rows land in Sheets, replies in drafts

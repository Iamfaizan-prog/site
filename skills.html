Process

How a build runs

The same four steps whether it is a one-file script or a service with an API.

01

Scope

We pick one manual step, measure how long it takes, and agree what a finished run looks like.

02

Build

A runnable script first, then the edges: retries, logs, and a review path for bad rows.

03

Handover

README, sample input, tests and a walkthrough. You can run it without me.

04

Maintain

Optional. Fixes and small changes after the first month, or a clean handoff to your team.

Adjacent: REST, JSON and CSV, cron, virtual environments, environment variables

Not sure which tool fits

Tell me the step and the file format. Choosing the tool is the easy part; the manual work is finding where the time actually goes.
